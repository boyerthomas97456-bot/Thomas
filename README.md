# Battle du panier

Version actuelle du jeu éducatif sur l'alimentation qualitative.

## Lancer le site

Ouvrir `index.html` dans un navigateur, ou publier le contenu de ce dossier sur un hébergeur statique.

## Fichiers principaux

- `index.html` : jeu et interface.
- `characters.png` : illustrations des personnages.

Le code est volontairement regroupé dans une page HTML autonome afin de faciliter la publication et les modifications.
